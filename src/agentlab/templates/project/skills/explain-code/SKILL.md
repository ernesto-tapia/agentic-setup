# Explain code

1. Read the relevant file(s) with `read_file`. Do not explain code you have not read.
2. Start with a one-sentence summary of what the code is for.
3. Walk through it top to bottom in plain language, grouping related lines.
4. Point out anything surprising: edge cases, bugs, or confusing names.
5. End with one suggestion to make it clearer.
